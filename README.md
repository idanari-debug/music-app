# המגירה

אפליקציה אישית לניהול שירים: טקסטים עם אקורדים, מגירות לפי שלב, מוכנות ופוטנציאל, טייפ ביטים, הקלטות ונגן.

## אבטחה

- כל שיר וכל הקלטה מוצפנים במכשיר לפני שהם עולים לענן.
- ההצפנה היא הצפנה סימטרית בתקן מתקדם עם מפתח של 256 ביט.
- מפתח ההצפנה נגזר מסיסמת הכספת, ולשרת מגיע רק מידע מוצפן.
- במאגר הזה יש רק את קוד האפליקציה. אין בו שום שיר, טקסט או הקלטה.
- הגישה לנתונים בשרת מוגבלת לבעלים בלבד, באמצעות הרשאות ברמת השורה.
